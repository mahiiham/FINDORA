# Login page rendering fix (11 November 2026)

The `/login` page failed with `LoginForm object has no attribute 'remember'`.

Cause: the `remember` and `submit` WTForms declarations were placed after a Python `#` comment on the same source line, so Python treated them as comment text and never created the fields.

Fix: restored `remember=BooleanField('Remember me')` and `submit=SubmitField('Login')` as separate class attributes in `app/auth/forms.py`. The existing login route and template already referenced these fields, so no login or authorization logic was changed. A regression test now checks that `/login` renders both controls.
